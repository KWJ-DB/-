# 우리 — 둘만 쓰는 커플 페이지

Cloudflare Pages + Pages Functions + D1(무료)로 동작합니다.

## 기능

- **홈**: 디데이(사귄 날 = 1일), 다가오는 기념일(100일 단위, 주년, 직접 추가한 생일 등), 오늘의 질문 현황, 우리 사이 거리, 최근 사진, 버킷 진행률
- **채팅**: 인스타 DM 스타일 1:1 채팅, 두 번 톡하면 하트, 길게 누르면 보내기 취소, 읽음 표시
- **오늘의 질문**: 매일 서술형 1개 + 둘 중 하나 고르기 1개. 내가 답해야 상대 답이 열림. 지난 질문도 답할 수 있음 (`public/questions.js`에서 질문 수정/추가)
- **캘린더**: 날짜별 일정 공유, 날짜별 사진 업로드(자동 압축), 기념일 표시
- **위치**: 벡터 지도(OpenFreeMap, 한국어 지명), 둘 사이 거리, 지금 보내기 / 실시간 공유 / 화면 꺼도 공유(OwnTracks 앱)
- **버킷리스트**: 추가, 완료 체크(완료 날짜 기록)
- **폰 맞대기**: 둘이 폰을 톡 부딪히면(동작 센서) 두 화면에 동시에 하트 애니메이션. "가까이 대기" 모드는 사람한테 거의 안 들리는 고음(18.5kHz / 19.4kHz)을 서로 내고 마이크로 들어서 가까워지면 반응
- 홈 화면에 추가하면 앱처럼 사용 가능 (Safari 공유 버튼 > 홈 화면에 추가)

## 배포

1. Cloudflare 대시보드 > **Storage & Databases > D1** > 데이터베이스 만들기 (예: `couple`)
2. **Workers & Pages > 만들기 > Pages > Git에 연결** > 이 저장소 선택
   - 프레임워크: 없음 / 빌드 명령: 비우기 / 빌드 출력 디렉터리: `public`
3. 프로젝트 **설정 > 바인딩 > D1 데이터베이스 추가**: 변수 이름 `DB`
4. **배포 > 다시 배포**
5. 사이트 접속 > 두 사람 이름, 사귄 날, 비밀번호 설정 (테이블은 자동 생성)

배포하자마자 처음 설정을 먼저 해두세요. 설정 전에는 주소를 아는 누구나 처음 설정을 할 수 있어요.

## 화면 꺼도 위치 공유 (OwnTracks)

위치 탭 > "꺼도 공유" 버튼에 입력값이 나옵니다.
Mode = HTTP, URL = `https://주소/api/owntracks`, UserID = 사이트의 내 이름, Password = 로그인 비밀번호.

## 알아둘 점

- 아이폰 Safari는 동작 센서 허용을 페이지를 열 때마다 다시 물어봐요(애플 정책). 사이트를 열고 처음 터치할 때 자동으로 물어보게 해뒀어요. 설정에서 끌 수 있어요.
- 진짜 NFC/블루투스 근접 감지는 웹에서 막혀 있어서 동작 센서와 소리로 대신해요. 둘 다 사이트를 켜둔 상태여야 해요.
- 사진은 D1에 저장돼요(장당 약 0.3MB, 무료 5GB).
