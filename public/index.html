화면 꺼도 위치 공유하기

웹페이지는 화면이 꺼지면 위치를 못 보내요. 무료 앱 OwnTracks가 대신 백그라운드에서 이 사이트로 위치를 보내도록 연결하면 돼요. (아이폰·안드로이드 모두 가능)

  1. App Store / Play 스토어에서 OwnTracks 설치
  2. 앱 설정(Settings)에서 Mode를 HTTP로 변경
  3. 아래 값을 그대로 입력
URL
UserID
Password
DeviceIDphone
  1. 위치 권한을 항상 허용으로 설정
  2. 지도 화면 위쪽에서 모니터링 모드를 Significant(배터리 절약, 수백 m 움직이면 전송) 또는 Move(자주 전송, 배터리 많이 씀)로 선택
이름과 방 코드는 이 사이트에 입력한 것과 똑같아야 같은 사람으로 표시돼요. 앱 지도에서도 친구 위치가 보여요. 공유를 멈추려면 앱에서 Quiet 모드로 바꾸거나 앱을 삭제하면 돼요.
