# 우리 — 둘만 쓰는 커플 페이지

Cloudflare Pages + Pages Functions + D1(무료)로 동작합니다.

## 기능

- **홈**: 디데이(사귄 날 = 1일), 다가오는 기념일(100일 단위, 주년, 직접 추가한 생일 등), 오늘의 질문 현황, 우리 사이 거리, 최근 사진, 버킷 진행률
- **채팅**: 인스타 DM 스타일 1:1 채팅, 사진 보내기, 두 번 톡하면 하트, 길게 누르면 반응 6종(하트·반짝·별·불·좋아요·포옹)/보내기 취소, 읽음 표시
- **오늘의 질문**: 매일 서술형 1개 + 둘 중 하나 3개(한 번 고르면 못 바꿈). 내가 답해야 상대 답이 열림. 매일 기록이 남음. 준비된 질문을 다 쓰면 자동 생성 질문이 끝없이 이어짐. 지난 질문도 답할 수 있음 (`public/questions.js`에서 질문 수정/추가)
- **추억**: 공유 앨범(월별 사진 모아보기) + 캘린더(날짜별 일정·사진·기념일)
- **위치**: 사이트를 열면 자동 공유(50m 이동 또는 2분마다), 화면 꺼도 공유는 OwnTracks 원터치 설정
- **버킷리스트**: 홈에서 열기, 완료 체크(완료 날짜 기록)
- **프로필 사진**: 설정에서 각자 사진 설정
- **같이 하트 누르기**: 홈의 하트를 둘이 동시에 누르면 두 폰에 같은 순간 애니메이션 (권한 필요 없음)
- **만남 감지**: 둘의 위치가 30~40m 안으로 가까워지면 "함께 있어요" + 만남 애니메이션·알림
- **알림**: 새 메시지, 장소 도착/출발 (아이폰은 홈 화면에 추가한 앱에서 설정 > 알림 켜기, iOS 16.4+)
- **장소**: 위치 탭 > 장소에서 학교·학원 등을 등록하면 도착/출발 시 상대에게 알림
- 홈 화면에 추가하면 앱처럼 사용 가능 (Safari 공유 버튼 > 홈 화면에 추가)

## 배포

1. Cloudflare 대시보드 > **Storage & Databases > D1** > 데이터베이스 만들기 (예: `couple`)
2. **Workers & Pages > 만들기 > Pages > Git에 연결** > 이 저장소 선택
   - 프레임워크: 없음 / 빌드 명령: 비우기 / 빌드 출력 디렉터리: `public`
3. 프로젝트 **설정 > 바인딩 > D1 데이터베이스 추가**: 변수 이름 `DB`
4. **배포 > 다시 배포**
5. 사이트 접속 > 두 사람 이름, 사귄 날, 비밀번호 설정 (테이블은 자동 생성)

배포하자마자 처음 설정을 먼저 해두세요. 설정 전에는 주소를 아는 누구나 처음 설정을 할 수 있어요.

## 화면 꺼도 위치 공유 (OwnTracks)

위치 탭 > "꺼도 공유" 버튼에 입력값이 나옵니다.
Mode = HTTP, URL = `https://주소/api/owntracks`, UserID = `a`(처음 설정한 사람) 또는 `b`, Password = 로그인 비밀번호, Authentication 켜기.

## 알아둘 점

- 진짜 NFC/블루투스 근접 감지는 웹에서 막혀 있어서 위치(GPS)로 대신해요.
- 사진은 D1에 저장돼요(장당 약 0.3MB, 무료 5GB).
